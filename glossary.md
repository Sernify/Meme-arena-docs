# Glossary

Quick reference for Meme Arena terminology.

---

**Accuracy Pool**
The peer-to-peer prediction pool for each match. Stakes from both sides are combined into a single prize pot, distributed to winning predictors proportionally.

**Active**
A token's status when it is eligible for matchmaking — sufficient liquidity, volume, and not in cooldown.

**ARENA Token**
The upcoming native utility and governance token of the Meme Arena platform, built on Solana.

**Archetype**
A character class assigned to a fighter token based on its performance profile (e.g., volatility, volume patterns). Displayed on the fighter profile page.

**Betting Window**
The 2-minute period before a match starts during which predictions can be placed. Closes when the round goes live.

**Bronze**
The lowest league tier. Fighters with a market cap under $100,000.

**Cooldown**
A rest period after a fight during which a token cannot be matched again. Tokens: 1-hour cooldown. Specific pairs: 4-hour cooldown.

**DexScreener**
A Solana DEX aggregator used by Meme Arena as a primary data source for token discovery and price data.

**Diamond**
The highest league tier. Fighters with a market cap over $10,000,000.

**Entry Fee**
A flat **15 Points** fee charged per prediction, separate from the stake. Goes to the platform, not the Accuracy Pool.

**Fight**
A best-of-3 series of Matches between two fighter tokens. Consists of 3 consecutive 5-minute rounds.

**Fighter**
A meme token that has been admitted to the Meme Arena and is eligible for matchmaking.

**Freeze Authority**
A Solana token permission that allows the issuer to freeze token holders' wallets. Must be revoked for a token to enter the Arena.

**Gold**
The third league tier. Fighters with a market cap between $1,000,000 and $10,000,000.

**Integrity Refund**
A 78% refund of a prediction stake issued when a fight is flagged for a data integrity issue (unable to score fairly).

**League**
One of four tiers (Bronze, Silver, Gold, Diamond) based on market cap. Fights only occur within the same league.

**Match**
A single 5-minute round between two fighters. One of three matches within a Fight.

**Matchmaker**
The automated system that pairs eligible fighters and schedules fights. Runs every 30 seconds.

**Mint Authority**
A Solana token permission that allows the issuer to create new token supply. Must be revoked for a token to enter the Arena.

**Net PnL**
Points won and refunded, minus Points staked and entry fees paid. Your all-time profit or loss in Points.

**Nonce**
A unique, time-limited random string generated by the server during wallet authentication. Signing the nonce proves wallet ownership.

**Points (pts)**
The in-platform currency used for predictions, earned through Accuracy Pool payouts, daily bonuses, and referrals.

**PumpFun**
A Solana token launchpad. PumpFun graduates (tokens that completed their bonding curve) are a key source of new Arena fighters.

**PumpPortal**
A real-time data feed for Pump.fun events — new mints and migrations.

**Round**
Same as Match — a single 5-minute head-to-head battle.

**Seed Token**
A hand-curated token address that is permanently active in the Arena, exempt from deactivation thresholds.

**Silver**
The second league tier. Fighters with a market cap between $100,000 and $1,000,000.

**Stake**
The number of Points you commit to a prediction. Enters the Accuracy Pool for that match.

**Streak**
The number of consecutive days you've claimed your daily bonus.

**Win Rate**
The percentage of your settled predictions that resulted in an Accuracy Pool payout.
