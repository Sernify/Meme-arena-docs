# Referrals

Invite friends to Meme Arena and earn Points when they join.

***

## Your Referral Code

Every account has a unique referral code visible on the **Profile** page. Click the copy button to grab your code.

***

## How It Works

1. Share your referral code or a referral link with friends
2. When they sign up using your code, the referral is recorded
3. You receive a **referral bonus** credited to your Points balance

***

## Finding Your Code

Go to **Profile** → look for the referral code section. You can share:

* The raw code (friend enters it during signup)
* A direct referral link (includes the code automatically)

***

## Notes

* Referral bonuses are credited after the referred user completes their first login
* Self-referral is not possible — you cannot use your own code
* There is no limit on the number of people you can refer
